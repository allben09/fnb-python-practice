### 📖 Description

The **FNB App Academy** is a multi-phase, industry-aligned digital skills programme delivered in partnership with the **University of Johannesburg**. It combines:

- 🎓 **Academic rigour** (UJ-accredited)
- 💼 **Industry relevance** (FNB-driven)
- 🚀 **Practical application** (Capstone project)
- 🌍 **Digital transformation** (4IR skills)
